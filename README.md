# My Portfolio

Portfolio pribadi Salvanus Adrian Michiels untuk menampilkan pengalaman dan kemampuan di bidang IT Support, Networking, Linux, Server, CCTV, infrastructure, dan DevOps tools.

## Tech

- HTML
- CSS
- JavaScript
- GitHub Pages

## Fitur

- Responsive desktop dan mobile
- Dark/light mode
- Smooth navigation
- Scroll reveal animation
- Section About, Skills, Experience, Projects, dan Contact

## Deploy ke GitHub Pages

1. Buka Settings repository.
2. Pilih Pages.
3. Pada Build and deployment pilih Deploy from a branch.
4. Pilih branch `main` dan folder `/ (root)`.
5. Save.

Setelah aktif, website akan tersedia di `https://vanus93.github.io/my-portfolio/`.
